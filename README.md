\# Cognifyz Technologies – Machine Learning Task 2



\## Restaurant Recommendation System



\### Project Overview

This project develops a Restaurant Recommendation System using Machine Learning techniques. It recommends restaurants based on user preferences such as city, cuisine, and price range.



\### Dataset

\- Dataset: Zomato Restaurant Dataset

\- Records: 1000

\- Features: 9



\### Technologies Used

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Scikit-learn

\- Joblib

\- Jupyter Notebook



\### Machine Learning Techniques

1\. Data Cleaning and Preprocessing

2\. Exploratory Data Analysis (EDA)

3\. TF-IDF Vectorization

4\. Cosine Similarity

5\. Restaurant Recommendation

6\. Recommendation Ranking
